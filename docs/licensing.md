## 你可以免费做什么

在**未获得商用书面授权**的前提下，允许：

- 下载、编译、运行 HaoVPN 源码或官方二进制；
- 个人学习、非商业研究、内网自用（非对外收费服务）；
- 按 LICENSE 使用，**不得**修改源码后对外分发或做衍生项目。

## 禁止做什么（无书面授权）

- 修改源码并发布修改版 / fork 后对外分发；
- 基于本项目做衍生产品并分发；
- **商用**：对外提供收费 VPN 服务、将 HaoVPN 打包进商业产品、SaaS 托管收费、营利性企业内部生产部署等。

## 什么算「商用」

典型商用场景（须联系作者获取授权）：

| 场景 | 是否商用 |
|------|----------|
| 工控现场自用、工程师接入内网 | 通常否（单组织内网运维） |
| 把 HaoVPN 作为产品卖给客户 | 是 |
| 对外提供「VPN 托管服务」并收费 | 是 |
| 修改 UI/功能后以新品牌分发 | 是（且涉及衍生） |

边界案例请发邮件与作者确认。

## 如何申请商用授权

1. 阅读 [LICENSE](../LICENSE) 全文；
2. 邮件联系作者（见 LICENSE 第 7 节「Contact」——**须由开发者填写邮箱**）；
3. 说明使用场景、部署规模、是否需要修改源码；
4. 双方签署书面授权协议后商用。

**本项目不在运行时做 license 校验**；合规依赖 LICENSE 法律条款与用户自觉。工控离线场景友好，无需联网激活。

## 授权管控流程（法律 + 发版流程）

```
使用者 → 阅读 LICENSE
       ├─ 非商用内网自用 → 部署官方二进制
       └─ 商用场景 → 邮件联系作者 → 书面授权协议 → 部署
```

| 层级 | 措施 |
|------|------|
| 法律 | [LICENSE](../LICENSE) 限制修改/衍生/商用 |
| 告知 | README、`-version`、`/api/v1/system/info` 指向 LICENSE |
| 发版 | [build-release.ps1](../scripts/build-release.ps1) 复制 LICENSE + NOTICE 到 `dist/` |
| 联系 | LICENSE §7（**开发者须填写邮箱**，非占位符） |
